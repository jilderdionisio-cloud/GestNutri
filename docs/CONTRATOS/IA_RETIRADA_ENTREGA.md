# IA retirada de esta entrega

Decisión del equipo: la formalización mediante IA (HU-11) queda retirada de esta entrega por no contar con proveedor, modelo ni credenciales. No está implementada, probada ni aprobada.

Se mantienen las notas manuales históricas y el resumen derivado exclusivamente de datos persistidos. No se presenta ninguna alternativa manual como IA.

Esta decisión no sustituye la aceptación del profesor: si HU-11 es obligatoria para la evaluación, el equipo debe solicitar una excepción o replanificar la entrega.

Pendientes restantes: documentos privados, auditoría efectiva, frontend conectado, pruebas PostgreSQL/E2E e integración con revisión humana.
